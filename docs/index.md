# Rgram: explore feature relationships

Rgram helps you explore how one numeric response varies with one numeric feature.
Use **regressograms** for interpretable bin summaries and **kernel regression**
for smooth local curves, with familiar scikit-learn fitting and pipeline APIs.

The single-feature scope is intentional. Fit separate curves for different
features or explicitly selected subgroups. These describe pairwise associations;
they do not adjust for other variables or identify causal effects.

Start with the quick start, read the theory and suitability guide to understand
what the curve means, then use the API reference for exact parameters, return
values, fitted attributes, warnings, and examples.
